# Extra fonts compiled into the FigCraft web app, on top of what upstream ships (Inter, Noto Sans
# Georgian, Archivo SemiBold). The browser app can't download fonts, so text in any other family
# falls back to Inter for people viewing in the browser.
#
# Each row is one file from Google's repository (https://github.com/google/fonts) at
# GOOGLE_FONTS_REF in the Dockerfile, under ofl/ (open-licensed fonts only: the web app is
# public, so anyone can take the fonts out of it). Fields are separated by " | ":
#
#   family | style | path under ofl/ | sha256
#
# style is Regular, Bold, Italic… for a static face, "Variable" / "Italic Variable" for a variable
# font, or "Licence" for the family's OFL.txt (one per family, required). The family must match
# the name the design files use. Changing this file needs a PACKAGE_REVISION bump in the Dockerfile.
